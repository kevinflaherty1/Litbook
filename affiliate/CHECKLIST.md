# Affiliate Site Launch Checklist

## Phase 1 — Niche
- [ ] Brainstorm 15–20 niche ideas
- [ ] Score top ideas with `templates/niche-scorecard.md`
- [ ] Choose one niche; narrow it to a winnable sub-niche
- [ ] List 100+ article ideas

## Phase 2 — Affiliate programs
- [ ] Search Amazon, Impact, CJ, Rakuten, Awin, PartnerStack, direct brands
- [ ] Build a program shortlist spreadsheet (rate, cookie, AOV, EPC, payout)
- [ ] Apply to easy-approval programs
- [ ] Note which programs need a live site first

## Phase 3 — Business setup
- [ ] Choose structure (sole prop / LLC)
- [ ] Open a separate business bank account
- [ ] Set up expense tracking
- [ ] Pick a brandable name; register domain and social handles

## Phase 4 — Website
- [ ] Choose platform and hosting
- [ ] Install theme / set up project
- [ ] Publish Home, About, Contact, Disclosure, Privacy, Terms
- [ ] HTTPS, sitemap, robots.txt
- [ ] Connect Google Search Console + Bing Webmaster Tools
- [ ] Set up analytics
- [ ] Set up link manager / `/go/` redirects with `rel="sponsored nofollow"`
- [ ] Add email signup form

## Phase 5 — Content
- [ ] Keyword research; group by intent
- [ ] Plan first 3 topic clusters
- [ ] Publish 10 articles (month 1)
- [ ] Publish 30–40 articles (by month 3)
- [ ] Every money page has: disclosure, top pick, comparison table, pros/cons, verdict

## Phase 6 — Traffic
- [ ] Internal links between every cluster article
- [ ] Schema markup on reviews
- [ ] Pinterest / YouTube / community presence started
- [ ] Lead magnet for email list
- [ ] First 5 legitimate backlinks

## Phase 7 — Optimize
- [ ] Track earnings per page monthly
- [ ] Improve top 10 earning pages
- [ ] Apply to higher-paying direct programs
- [ ] Refresh content older than 6–12 months
- [ ] Apply for display ads when eligible

## Phase 8 — Scale
- [ ] Write style guide + SOPs
- [ ] Hire first writer
- [ ] Decide: expand niche or launch site #2
